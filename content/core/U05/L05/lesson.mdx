<Step id="S3">
Bar 2 is the chord that let the bass step from C to B. Run the loop and look at it closely.

<Example id="the-chords" views="code,roll" />

<OnPass>B, D, G: every note of G, with the 3rd at the bottom. A triad with a note other than its root lowest is an **inversion**. With the root lowest it is in root position; with the 3rd lowest, first inversion; with the 5th lowest, second inversion. The name of the chord stays G. Only its floor moved.</OnPass>
</Step>

<Step id="S4">
The same trick in another loop. One chord stands on its root and breaks the line under it.

<Editor exercise="let-it-walk" />

<OnPass>E, G, C: a C chord in first inversion, and now the lowest notes walk F, E, D before G. Rearranging the notes changed the line under the chords, not the chords.</OnPass>
</Step>

<Step id="S5">
Your ear follows the lowest note. With the root there, a chord sounds planted; with the 3rd there, it sounds lighter, as if it could move.

<EarDrill family="fam.chd.inversion" level={1} trials={8} />

<OnPass>Root position stands still; first inversion leans. Bass players use that lean to walk from chord to chord.</OnPass>
</Step>

<Step id="S6">
A name can carry the lowest note too: write the chord, a slash, then the note at the bottom.

<Choice exercise="name-it-with-its-bass" />

<OnPass>C, F, A is F, A, C rearranged, an F chord with C lowest: F/C. A name with its bass note after a slash is a **slash chord**. C/E is a C chord with E at the bottom, the one you built in Let it walk.</OnPass>
</Step>
