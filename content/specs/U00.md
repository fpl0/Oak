Two short sessions before the course proper. U00.L01 is the wow: a four-layer loop, one number changed by the learner, the tutor's first words and Sketch 001, in about eight minutes. ## Conventions for this unit

- Both lessons use the onboarding loop (`ONBOARDING_LOOP` in content/specs/U00.ts, the STYLE §14 opener with named labels). Copy it into the lessons as a constant; do not vary it between U00.L01 and U00.L02. content:check and the grader treat all U00 code as a preview context (`ONBOARDING_PREVIEW` in content/validate/harness.ts), so its locked tools lint clean there and nowhere else.
- The learner edits only `n` values in the melody line (the 'one editable number' of rule 5a): mark them as editable regions (`⟪…⟫`) and use `edit-only-regions` where a step is checked. No other tool is taught or named: the Coda's Toolbox ceremony, not the prose, says what unlocks.
- Setup screens (headphones, mic, noise, bleed, tap latency, range) are app screens from ux §4.7, mounted inside `concept` steps with the MDX component `<Setup part="…" />` (content/lib/mdx.ts). They store the learner profile; the lesson does not grade them.
- U00 Makes need no Band: the onboarding loop is already a full band. Set `ui.band: false` with a one-line reason comment.
- Voice: this is the learner's first ten minutes. Short sentences, no theory words before their sound (no 'tonic', 'scale', 'degree', 'chord' as teaching), no promises about what the app hears beyond what it measures. Mic copy, verbatim: 'Your voice is analysed live on this computer. Nothing is recorded or sent.'

## U00.L01 Hello, Loop

Author: **U00**. Key C major, 4/4, 92 BPM.

**Objective (syllabus).** ~8 min. Start sound, hear a four-layer loop build up, change one number and hear it land, paste the API key in the app (skippable), meet the tutor, save Sketch 001.

**The one idea.** Code makes music here: each line is a musician, and changing one number changes what you hear.

**Sound first.** The onboarding loop building up: drums alone, then bass, then chords, then the piano melody (one listen item per layer). (a `preview: true` example)

```js
setcpm(92/4)

drums: s("bd ~ sd ~, hh*8").bank("RolandTR808").gain(.8)
bass: note("<c2 a1 f1 g1>").s("ebass").lpf(800)
chords: chord("<C Am F G>").voicing().s("rhodes").gain(.5)
mel: n("<[4 ~ 2 4] [0 ~ ~ 2] [5 ~ 3 5] [4 ~ ~ ~]>").scale("C4:major").s("piano")
```

**Skills.** Introduces: D01 Timbre & palette. Practises: none.

**Terms (≤ 3, a pair counts once).** `term.loop` "loop" in S1: A short pattern that repeats until you stop it. `term.timbre` "timbre" in S2: The colour of a sound: what makes a piano and a bass sound different on the same note.

**Can-do.** `cd.code.first-loop` "I can start, stop and change a loop in code."

**Unlocked here (content/toolbox.ts).** `tb.feature.transport` `tb.feature.roll` `tb.feature.studio` `tb.feature.tutor` `tb.feature.band` `tb.label`

**Tools the learner's code uses.** `tb.label` `tb.feature.transport` `tb.feature.roll` `tb.feature.studio` `tb.feature.tutor`

**Steps.**

| Step | Kind | Exercise | Answer | Min | Graded | What | Term |
|---|---|---|---|---|---|---|---|
| S1 | listen | listen | — | 0.75 |  | Four items: drums; + bass; + chords; + melody (the loop builds up). Roll in part colours, no staff. | term.loop |
| S2 | investigate | run-investigate | choice | 0.75 |  | Mute lines with the buttons: which line plays the lowest notes? (bass) Which sounds like a piano? | term.timbre |
| S3 (wrap) | modify | code-modify | code | 1 |  | Change the highlighted last melody number (`⟪4⟫`) to any number from 0 to 7 and run. Not graded: any change passes (`edit-only-regions`, `max-changed-tokens` 1); the unchanged starter fails with `code.unchanged`. |  |
| S4 | concept | — | — | 0.75 |  | Meet the tutor: it is docked on the right and knows this lesson; one suggested question. The connection card (API key or Claude login) is the onboarding flow's `onb.tutor` screen, skippable. |  |
| S5 | make | code-make | code | 1.5 |  | Sketch 001: change anything in the melody line, then save. |  |

**Budget (§9.2).** 5 steps, 0 graded; expert 4.75 min × 1.4 = 6.65 scaled (cap 13). Split at S3: part A 3.50 (cap 8.5), part B 3.15 (cap 9.5).

**Make.** Make the loop yours: change any of the melody's numbers, run it, and save it as Sketch 001.

- Required rule (exactly one): `tracks`, "The loop still plays (at least two parts)". `tracks` min 2. Saving is never blocked; the rule only catches a loop the learner emptied by accident.
- Suggestions: the melody changed (no generic rule: leave it to the tutor's first note).
- Band: `false` (no Band). Flavours: No Band; the flavour choice is made later in onboarding (`onb.prefs`).

**SRS.** none. Fact cards: none.

**Mistakes the tests must pin (feedback codes as the grader emits them).**

- unchanged starter in the modify: `code.unchanged`
- edited outside the highlighted number: `code.edit-outside`

**Connects.** Back: Nothing: this is the first screen after 'Start sound'. Forward: U00.L02 sets up the ears and the voice; U01.L01 takes the drums apart.

**Notes.**

- The deterministic reaction keyed by the chosen number (ux §8 `onb.react`, 8 variants) is app copy owned by the onboarding flow; the lesson's own pass text stays general and true for every value.
- Two terms: `term.loop` (S1 pass text, after the loop has played) and `term.timbre` (S2).

## U00.L02 Set Up & First Sing

Author: **U00**. Key C major, 4/4, 92 BPM.

**Objective (syllabus).** ~12 min. Headphones (with AirPods guidance), mic, noise and bleed, vocal range, tap and sing latency; a lenient first sung tonic (the tonic plays first; any sustained pitch within ±100¢ after octave folding passes).

**The one idea.** Oak can hear your taps and your voice; your first sung note finds the place the loop calls home.

**Sound first.** The onboarding loop, softly, under the setup screens; it returns at the end for the second sketch. (a `preview: true` example)

```js
setcpm(92/4)

drums: s("bd ~ sd ~, hh*8").bank("RolandTR808").gain(.8)
bass: note("<c2 a1 f1 g1>").s("ebass").lpf(800)
chords: chord("<C Am F G>").voicing().s("rhodes").gain(.5)
mel: n("<[4 ~ 2 4] [0 ~ ~ 2] [5 ~ 3 5] [4 ~ ~ ~]>").scale("C4:major").s("piano")
```

**Skills.** Introduces: V01 Sustain & match a pitch. Practises: none.

**Terms (≤ 3, a pair counts once).** none

**Can-do.** `cd.sing.first-note` "I can sing back a note I hear."

**Unlocked here (content/toolbox.ts).** `tb.feature.tuner`

**Tools the learner's code uses.** `tb.feature.tuner` `tb.label`

**Steps.**

| Step | Kind | Exercise | Answer | Min | Graded | What | Term |
|---|---|---|---|---|---|---|---|
| S1 | concept | — | — | 1 |  | Headphones on: `<Setup part="headphones" />` (L/R test, device type, AirPods and Bluetooth guidance). |  |
| S2 | concept | — | — | 1.25 |  | Microphone: `<Setup part="mic" />`, `<Setup part="noise" />`, `<Setup part="bleed" />`, with the privacy line. |  |
| S3 | concept | — | — | 1 |  | Tap timing: `<Setup part="tap-latency" />` (16 clicks at 90 BPM). |  |

| S6 | make | code-make | code | 2 |  | Sketch 002: the loop again; make the melody end on the note you just sang (home). |  |

**Budget (§9.2).** 6 steps, 0 graded; expert 8 min × 1.4 = 11.20 scaled (cap 13). Split at S4: part A 6.65 (cap 8.5), part B 4.55 (cap 9.5).

**Make.** The loop is back, and this time the band ends on its home chord (bar 4: C instead of G, so the home note is not a sus4 over G). Change the last melody number so the tune ends on the note that feels like home too, then save.

- Required rule (exactly one): `ends-on-degree`, "The melody ends on the home note". `ends-on-degree` ["1"] on `mel`: the learner's ear found home in the sing step; the code makes it land there (`0` or `7`). The word 'degree' stays out of the prose.
- Suggestions: none.
- Band: `false` (no Band). Flavours: No Band.

**SRS.** `fam.pit.match` (seed). Fact cards: none.

**Mistakes the tests must pin (feedback codes as the grader emits them).**

- unchanged loop (ends on 5): `rubric.unmet`

**Connects.** Back: U00.L01's loop and its editable melody numbers. Forward: U01.L01 starts the course with the pulse; singing returns in U02.L07 and from U03.L02 on numbers.

**Notes.**

- Contracts §2.3 asks for 'any sustained pitch within ±100¢ after octave folding'. `SingTolerance.cents` tops out at 70 in the schema; use `cents: 70, octave: "global"` and report the gap (the schema needs a calibration value of 100).
- The sing step is never graded (`graded` unset) and never blocks: Quiet mode or no microphone skips it.
- Sing tests are pending in content CI (no recorded fixtures).
