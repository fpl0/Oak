## Needs you

- **Listening pass on instruments.** The curated aliases (`rhodes`, `upright`, `ebass`, `organ`, guitars, `strings`, `horns`, `tenor`) were chosen by file and name, not by ear. Open `/dev/listen` and tell me which sound cheap.
- **Ten-day trial.** The Wave 2 gate "you use it for 10 days, median session within budget" can only be met by you. Telemetry is recorded locally from the first session (`/dev/telemetry` shows it).
- **Does skill mastery fade with time away?** The contract says a mastered skill drops back to "practiced" when its recall estimate decays far enough, even with no new mistakes. The robustness review changed this so a level moves only on new evidence; time away shows only as the leaf fading on the Oak (decision 22). Say if you want the contract's stricter rule back.
- **Should Today's warm-up count against the 12-minute "a little more" review cap?** It now does (decision 23): on a day you already did a long warm-up, "a little more" offers less.
- **Two tabs, one session.** Today a second tab can start a second session and both count. Wave 3 changes this so the second tab joins the open session (decision 28). Say if you would rather keep them separate.
- **Jazz-soul drums.** The jazz-soul flavour's kit is, for now, the default acoustic kit (decision 24). If you choose that flavour, listen at `/dev/listen` and say whether you want a real brushes-and-ride kit mirrored.
